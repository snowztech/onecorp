# Untitled AI company app

Name to be decided. Working names so far: Crew HQ, OneCorp (onecorp.dev is taken).

A desktop app where one person runs a real company staffed by AI employees. You hire a PM, engineers, a designer, a reviewer, marketing. They pick up tickets, talk in channels, write real code in a real git repo, and ask you when they need a decision.

The pitch: **one human, a small AI team, real output, and you always know what's happening and what it costs.**

## Principles

1. **Real output.** Code lands in git, PRs get opened, posts get drafted. Not a simulation.
2. **Human in the loop.** You're the founder, not a spectator. The app makes your decisions fast.
3. **Small teams.** 3 to 6 narrow roles with real tools beat a fake org chart full of VPs.
4. **Talk only in tickets.** Agents message each other inside a ticket thread or when blocked.
5. **Typed handoffs.** Design hands dev a spec, dev hands review a PR.
6. **Hard budgets.** Per employee and per company. Pause at the cap and ask.
7. **Company as code.** Roles, tools, budgets and reporting lines live in `company.yaml`.
8. **Fun on top, never in the way.** Personality changes tone, never the work.
